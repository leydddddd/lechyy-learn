# M4.8 Compatibility Matrix

One-page reference for the four target sites that validate the Lechyy extension
against the rendering patterns it will encounter in the wild.  Each row records
the target URL category, the server-side fixture that emulates it, the M4
performance budget, and the observable acceptance checks that every run must
pass.

Performance numbers are illustrative baselines — record actual measured values
below each budget row when profiling on the agreed development machine.

## Targets

| # | Target category | Fixture route | Emulated characteristics |
|---|---|---|---|
| 1 | Static novel site | `/novel` (see M4.8-static.html) | A single-page web-novel chapter with ~60 paragraphs, each 40–120 chars of Chinese prose, mixed with a static navbar/ad container that contains no CJK. Mirrors real sites like `radish.io` or `wuxiaworld.com` article pages. |
| 2 | Infinite-scroll reader | `/infinite-scroll` (server.mjs) | Initial 15 paragraphs visible, a button that appends 10 paragraphs at a time. Tests the M4.4 MutationObserver idle-annotation loop on newly injected DOM. |
| 3 | SPA (router-based) | `/spa` (see M4.8-spa.html) | A single HTML file with Vue / React–style client routing: two "pages" inside `<div id="app">`, switchable via client-side `history.pushState`. Page 1 has 30 paragraphs, page 2 has 45 paragraphs. The extension must annotate both routes without reloading. |
| 4 | Large general Chinese page | `/large-general` (see M4.8-large.html) | A 150-paragraph page with mixed content types: headings, lists, quoted blocks, inline code, tables, and advertisements — simulating a news portal or general-purpose Chinese content site like `ifeng.com` or `sina.com.cn` article page. |

Budgets apply to **Lechyy-attributable** main-thread work only.  Exclude third-
party ad scripts, analytics, and framework render cycles.

## Acceptance Checks per Target

### 1. Static novel site

- [ ] All 60 paragraphs contain `<ruby[data-word]>` elements after idle callbacks settle.
- [ ] No ruby elements appear inside navbar/ad container (non-CJK area).
- [ ] Tooltip on hover shows CEDICT entry or per-character pinyin fallback.
- [ ] Copy selection from ruby text returns original Chinese characters.

### 2. Infinite-scroll reader

- [ ] Initial 15 paragraphs annotated during first paint.
- [ ] After clicking load-more button (appends 10 paragraphs), new paragraphs get annotated within 3 seconds without page reload.
- [ ] No duplicate ruby markup on the initial paragraphs after scroll-in of new content.
- [ ] MutationObserver does not fire for Lechyy's own DOM mutations.

### 3. SPA

- [ ] Route 1 renders and its paragraphs get annotated.
- [ ] Navigating to Route 2 (client-side, no page reload) causes Route 2 paragraphs to be annotated without re-injection issues.
- [ ] Navigating back to Route 1 does not double-annotate (ruby elements stable).
- [ ] Tooltip generation counter survives SPA navigation (M4.7).

### 4. Large general Chinese page

- [ ] All CJK paragraphs annotated (150 paragraphs).
- [ ] Non-CJK containers (ads, footers) produce 0 ruby elements.
- [ ] No ruby elements inside `<code>`, `<pre>`, `<script>`, `<style>` tags.
- [ ] Total annotation time for 150 paragraphs: under 1 second on reference hardware.

## Notes

- Fixture routes `/novel` and `/spa` and `/large-general` are defined in `e2e/m4-8-fixture.mjs`.
- The server serves these fixtures alongside the existing routes from `e2e/server.mjs`.
- `e2e/m4-8.spec.ts` runs all four categories as Playwright test files.
